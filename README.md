Description
This tool will collect useful information regarding your Skyrim and Vortex environment, and perform a few sanity checks to help you, or your support team, get your game up and running ASAP.  This tool was almost completely coded by AI.

Main features
System, Game, and Mod info at a glance
Links to log locations and Skyrim SE game folder
Vortex update reminder even if you've closed the notification and forgot about it
View suppressed notifications and click to reset
Attempts to detect if the Skyrim Special Edition DLC has been purchased for mod compatibility. Steam doesn't provide an infallible way to do this, so a manual override is available. 
Click to copy your SKSE path, restore a deleted SKSE tool, or repair it if the actual location doesn't match the tool's location
Identify mod files (meshes, animations, textures, DLLs, plugins) that are were not installed by Vortex 
       Unmanaged files can be forgotten - old mods, manually installed mods - and conflict with new mods you install
       Unmanage files are not always bad, but it's good to have visibility in any case 
Screenshot button
Immersive Discord link if you need support for one of the Immersive Collections

Usage
Look for the "Immersive Support" tab in vortex, while Skyrim SE/AE is selected.  Additional game support may come in the future and will be found in the Support Stats tab for supported games. 

Toggle the check box if the extension incorrectly detects AE DLC
 


Installation instructions:
Vortex: 
- Simply click the Vortex button above or in Vortex go to Home then the Extensions tab in the vertical list of tabs. At the bottom of the page click "Find More" and search for "Support Stats" then click to install
- You can also manually download the file and drop the archive into the Drop Files area of the extensions tab, then restart Vortex


Manual install: Download and extract to %appdata%\Vortex\Plugins
Compatibility:
Most functionality should with with Vortex 1.15.2+, but the extension was made with version 2.0+ in mind. Let me know if you have issues with versions prior to 2.0 but no guarantees I'll be able to fix it.
